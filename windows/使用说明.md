# Format Kit 2.0.4

适用于 Windows 10 和 Windows 11 的 x64 便携应用。歌曲库、转换进度和批次结果都在同一个本地页面。

## 启动

1. 解压整个 ZIP，双击 **Start Format Kit.exe**。启动器会用默认浏览器打开本地页面。应用已带转换引擎、FFmpeg 和 Python 运行时。
2. 点 **目录设置**，选择 QQ 音乐的下载目录和一个不同的导出目录。会员歌曲可能保存在 `VipSongsDownload`。可以在 QQ 音乐客户端设置中查找实际位置。
3. 勾选歌曲，选择输出格式，再点 **开始转换**。已写好的文件会出现在导出目录，进度与逐首结果可在页面查看。
4. 退出时点侧栏的 **退出**。浏览器标签关闭后，也可以再次双击启动器回到同一个本地服务。控制台版 `.cmd` 可用于诊断启动问题。

## 转换和整理

- **保持原格式**保留源编码。`.mflac`、`.qmcflac` 的 FLAC 音源输出为 FLAC。`.mgg` 的 OGG 音源保留为 OGG。
- **MP3**档位为 V0、V2、V5、V7。实际码率随音频内容而变。若解密后已是 MP3，转换核心会保留原 MP3。
- `musicex` 新版文件沿用 Kugo 转换核心的联网流程。请在 QQ 音乐客户端保持有效登录，并确保当前账号拥有歌曲权限。旧版带内嵌密钥的格式可以离线转换。
- 应用每隔约 12 秒检查下载目录，也可以手动刷新。首次扫描建立基准，后来发现的文件会标为新增。
- 歌名和歌手来自常见的「歌手 - 歌名」文件名。音质按扩展名估计，无法确定时显示「未知」。中文歌曲按拼音规则排序。
- 批次支持取消，已导出的文件会保留。失败原因显示在转换历史中。同名文件会增加序号。
- 设置和批次历史保存在 `%LOCALAPPDATA%\format-kit`。本地应用服务只监听 `127.0.0.1`。

## 组成和验证

新版应用使用独立设计的网页、歌曲目录和历史模块。转换进程由 Kugo Music Converter v0.6.1 的 GPL-3.0 源码编译，通过本地进程传递音频路径、转换进度和结果。引擎源代码、编译方法和第三方许可证放在 `source` 与 `licenses`。

开发验收在 macOS 运行了真实的旧式 QMC 音频转换，并使用 Chrome 验证界面与批次流程。Windows x64 文件已交叉编译并核对架构。Windows 启动与新版 QQ 音乐联网转换尚未在 Windows 实机验证。
