# 第三方组件

## Kugo Music Converter

- 上游版本 [v0.6.1](https://github.com/skxxxkx666/Kugo-Music-Converter/tree/v0.6.1)。
- 转换引擎按 GPL-3.0 发布，许可证副本见 `KUGO-GPL-3.0.txt`。
- 转换入口和日志适配的源码位于 `windows/engine`。构建时将它们分别加入上游的 `backend/cmd/qqmusic-decoder-engine` 和 `backend/internal/logger`，并把对应源码一起放入便携包的 `source/kugo-engine`。

## FFmpeg

- 文件来自 [imageio-ffmpeg 0.8.1 的 Windows x64 wheel](https://pypi.org/project/imageio-ffmpeg/0.8.1/#imageio_ffmpeg-0.8.1-py3-none-win_amd64.whl)。
- 该二进制为 Gyan.dev 发布的 `9.0.2-essentials_build-www.gyan.dev`，启用了 GPL 和 version3。
- 对应 [FFmpeg 9.0.2 源码](https://github.com/FFmpeg/FFmpeg/tree/n9.0.2) · [Gyan.dev 构建发布和依赖信息](https://www.gyan.dev/ffmpeg/builds/) · [imageio-ffmpeg 发布构建](https://github.com/imageio/imageio-ffmpeg/tree/26277bb102b64c42d939c3a550301edbe2c81921)。
- Windows wheel 的 SHA-256 为 `f27ca4cb85e2d4946deedbce1a81245dfd942a2bcf94b53676fb3956aa95bf1b`。
